# Changelog

## Sprint 3 — навигация сетевого справочника

- Подключён Expo Router, маршруты в `src/app/`: корневой Stack, вкладки «Каталог» и «О приложении», карточка `topic/[id]`, `+not-found`.
- Карточка товара стала отдельным экраном вместо окна. Переход передаёт только id, включены typed routes.
- id из адреса проверяется во время работы (`parseTopicId`), при неверном id запроса к серверу нет.
- Карточка открывается по прямой ссылке без загрузки списка, без истории в шапке кнопка «В каталог».
- Отдельные сообщения для неизвестного адреса, неверного id, отсутствующего товара и ошибки сети.
- Поиск, фильтры и прокрутка каталога сохраняются при возврате из карточки и при переключении вкладок.
- `useTopic` принимает `string | undefined`, при смене id сбрасывает прежнюю карточку и отменяет старый запрос.
- Отметки для дозаказа вынесены в `SelectionProvider`, общие для каталога и карточки.
- Защита от двойного нажатия по товару.
- Экран «О приложении».
- Панель тестового режима сети есть и на экране карточки.
- Добавлены схема экранов, схема хранения данных и протокол проверок навигации (`docs/navigation.md`), тест разбора id.

## Sprint 4 — сетевой каталог

- Каталог загружается из DummyJSON: весь список одним запросом, поиск и фильтры работают по нему локально, вывод порциями по 20.
- Сетевая часть разделена на уровни: `transportService` (fetch, timeout 10 с, отмена, ошибки, логи) → `apiManager.products` (`list`, `getById`, проверка DTO, преобразование в `Topic`) → hooks.
- Добавлена runtime-проверка ответа сервера (`parseProduct`, `parseProductList`) и ошибки `http_error`, `network_error`, `timeout`, `cancel`, `parse_error`, `contract_error`.
- Состояния экрана: загрузка, ошибка с кнопкой «Повторить», пустой результат, успех.
- Карточка товара открывается поверх списка и сама загружает товар по id, 404 показывается как «Товар не найден». После закрытия поиск, фильтры и прокрутка сохраняются.
- Отмена запросов при уходе с экрана и защита от устаревших ответов.
- Демо-режим: тестовые данные включаются только кнопкой и подписаны «Демо-данные».
- Тестовый режим сети для проверки ошибок (только в режиме разработки).
- Логи запросов: `http.start`, `http.end`, `api.contract_error` с `requestId`, маршрутом, статусом, длительностью и итогом.
- Автотесты на Jest: проверка DTO, обработка ошибок в transportService, защита от устаревшего ответа.
- Добавлены названия всех 24 категорий DummyJSON, компоненты `StockBadge` и `StatusView`.
- Документы: контракт API и команды curl (`docs/api.md`), протокол проверок и разбор логов (`docs/network-checks.md`).

## Sprint 2 — интерактивный локальный каталог

- Список товаров переведён на `FlatList` с `renderItem` и `keyExtractor` по id товара.
- Добавлен управляемый поиск по названию и артикулу без учёта регистра. Поиск срабатывает через 300 мс после ввода (`useEffect` с таймером и cleanup).
- Добавлены фильтр по категории и фильтр «Только заканчивающиеся», кнопка «Сбросить».
- Добавлено пустое состояние «Ничего не найдено» с кнопкой сброса.
- Товары можно отмечать для дозаказа, внизу экрана счётчик отмеченных и кнопка «Очистить». Отметки хранятся в state и обновляются без мутации массива.
- Логика каталога вынесена в hook `useCatalog`, фильтрация в отдельную функцию `filterTopics`.
- Добавлен компонент `Chip` для кнопок фильтра.
- В тестовые данные добавлено 5 товаров (косметика и ноутбуки), всего 12.
- Добавлена ретроспектива Sprint 1 и Sprint 2.

## Sprint 1 — статическая витрина

- Создан проект на React Native + Expo с TypeScript.
- Добавлен тип товара `Topic` и функция определения статуса остатка.
- Добавлены тестовые данные: 7 товаров из разных категорий.
- Добавлен переиспользуемый компонент `TopicCard`: картинка или заглушка, название, категория, артикул, остаток, цена и статус.
- Экран каталога выводит все товары через `TopicCard`, по нажатию показывается остаток товара.
- Добавлены скрипты `typecheck` и `lint`.
