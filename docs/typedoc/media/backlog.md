# Product backlog

Формат истории: «Как <роль>, я хочу <действие>, чтобы <цель>».

## US-1. Список товаров с остатками

Как продавец, я хочу видеть список товаров с остатками, чтобы быстро понять, что есть на складе.

Приоритет: высокий. Спринт: 1. Статус: сделано.

Критерии приёмки:
1. После запуска приложения на экране отображается не меньше трёх карточек товаров.
2. В каждой карточке есть название, категория и остаток в штуках.
3. Если у товара нет картинки, вместо неё показывается заглушка, и вёрстка карточки не ломается.
4. При нажатии на карточку вызывается обработчик, который получает id товара.

## US-2. Поиск по названию

Как продавец, я хочу найти товар по части названия, чтобы не листать весь список, пока покупатель ждёт.

Приоритет: высокий. Спринт: 2. Статус: сделано.

Критерии приёмки:
1. Поиск работает по части названия и не зависит от регистра.
2. Пустая строка поиска показывает весь каталог.
3. Если ничего не найдено, на экране написано об этом и есть кнопка сброса.

Дополнительно сделан поиск по артикулу: продавцу иногда проще ввести код с ценника.

## US-3. Фильтр по категории

Как продавец, я хочу оставить в списке только одну категорию, чтобы быстрее найти похожие товары.

Приоритет: средний. Спринт: 2. Статус: сделано.

Критерии приёмки:
1. Категории показаны чипами, выбранная выделена цветом.
2. Чип «Все» снимает фильтр по категории.
3. Фильтр работает вместе с поиском.

## US-4. Заканчивающиеся товары

Как товаровед, я хочу видеть только товары с маленьким остатком, чтобы вовремя заказать их у поставщика.

Приоритет: средний. Спринт: 2. Статус: сделано.

Критерии приёмки:
1. Переключатель «Только заканчивающиеся» оставляет товары с остатком меньше 10 штук, включая нулевой.
2. Кнопка «Сбросить» снимает этот фильтр вместе с остальными.

## US-5. Список на дозаказ

Как продавец, я хочу отмечать товары для дозаказа и видеть, сколько отмечено, чтобы передать товароведу готовый список.

Приоритет: средний. Спринт: 2. Статус: сделано.

Критерии приёмки:
1. Кнопка на карточке отмечает товар, повторное нажатие снимает отметку.
2. Один товар нельзя отметить дважды, счётчик совпадает с числом отмеченных карточек.
3. Отметки не пропадают при поиске и смене фильтров.
4. Кнопка «Очистить» снимает все отметки.

Пока отметки живут только до перезапуска приложения, сохранение будет в следующих спринтах.

## US-6. Актуальные данные с сервера

Как продавец, я хочу, чтобы список загружался с сервера, а при ошибке сети можно было повторить загрузку, чтобы видеть реальные остатки.

Приоритет: высокий. Спринт: 4. Статус: сделано.

Критерии приёмки:
1. При открытии приложения список загружается с DummyJSON, во время загрузки виден индикатор.
2. Если сервер недоступен или ответил ошибкой, на экране понятная причина и кнопка «Повторить».
3. Пока идёт загрузка, второй такой же запрос запустить нельзя.
4. При ошибке можно явно включить демо-данные, и они подписаны «Демо-данные».
5. Поиск, фильтры и отметки из Sprint 2 работают с данными сервера.

## US-7. Карточка товара

Как продавец, я хочу открыть подробную карточку с артикулом, брендом и минимальной партией заказа, чтобы ответить на уточняющие вопросы.

Приоритет: средний. Спринт: 4 (загрузка по id), 3 (отдельный экран). Статус: сделано.

Критерии приёмки (Sprint 4):
1. Карточка сама загружает товар с сервера по id.
2. Показаны бренд, категория, артикул, цена, остаток со статусом, минимальная партия заказа и описание.
3. Если товара нет на сервере, написано «Товар не найден».
4. После закрытия карточки список остаётся с тем же поиском, фильтрами и местом прокрутки.

Критерии приёмки (Sprint 3):
1. Карточка — отдельный экран с адресом `/topic/{id}`.
2. Возврат стрелкой или системной кнопкой «Назад» сохраняет поиск, фильтры и прокрутку.
3. Отметка «В дозаказ» на экране карточки видна и в каталоге.

## US-8. Ссылка на товар

Как товаровед, я хочу отправить коллеге ссылку на карточку товара, чтобы он сразу открыл нужную позицию.

Приоритет: низкий. Спринт: 3. Статус: сделано.

Критерии приёмки:
1. Ссылка `/topic/{id}` открывает карточку сразу, даже если каталог ещё не открывали.
2. Если в ссылке не число, показывается «Неверный номер товара», запроса к серверу нет.
3. Если такого товара нет, показывается «Товар не найден».
4. Из карточки, открытой по ссылке, можно перейти в каталог кнопкой «В каталог».
